2026年10月16日

如图，这天13：21，发了消息通知我，维修师傅去a411维修,

当时我在和微信电话和我哥说这件事，内容是昨天21：23和前台通话和今天早上10：22和前台通话的内容，

因为微信有防ios录音录屏功能，我没有录屏成功，大致内容是解决a411空调有异味的事，在后面现场录的视频也有提到过

，

和我哥通话时，我一时内急进入厕所，此时我暂住在他们给我提供的a307。

通电话期间我看到了前台发的信息，说让维修师傅和我去看一下，我和我哥挂断后，我就直接打电话问是不是他们在敲门，他们说让我一起上去，我说你们直接上去修就行了，我现在不方便，

大概几分钟后我上完厕所后，穿好衣服上去看看怎么样了，谁知打开门一看根本没人，

于是打电话询问没看到维修师傅，后来我走到楼梯口WiFi断了因此显示电话中断，

15：13，微信消息告诉我地上全是水，

我17：18看到消息后打电话询问，因为我后脚跟上去看到地上没有水，猜测可能是维修师傅去错房间了，电话中就问是哪个房间地上有水，确认是a411后，让她们和我一起确认一下是否有水，

我走到电梯口，一共四个电梯，便查看哪个是上楼，左手第一个有点像，因为前台在2楼，电梯在2楼停了一下，然后开始向上，我在3楼，就按了一下上键，然后在电梯开门前意识到可能会扯皮陷害就打开了手机摄像头

。

我说你打电话给维修师傅，我问清，地上有没有水，

究竟咋了要前台发微信给我扣这么大帽子，说地上有水怎么回事，搞得我以为是维修师傅进错房了，

因为离得远，我就说你开外放，我说我进屋了，你看我听不听得到，然后她才不情不愿地走到门口，走廊都是监控，有一个监控正对a411，维修师傅只在电话中讲他会过来，我就坐在我的小马扎上说你是那个啥都会修的吗，是的话你修不了，因为这个维修工已经来过很多次说修不了，
